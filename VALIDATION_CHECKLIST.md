# VALIDATION CHECKLIST - Перевірочний список для захисту

Цей документ містить повний перелік критеріїв, які мають бути виконані для успішного захисту магістерської роботи з використанням AutoRL комплексу.

## 📊 Статистичні вимоги

### Вибірка та потужність
- [ ] **n ≥ 30** незалежних запусків (random_seed) на кожну конфігурацію
- [ ] **Statistical Power ≥ 0.8** для основних порівнянь
- [ ] Фіксація seed на рівні: numpy, random, torch/tf, gymnasium

### Статистична значущість
- [ ] **p < 0.05** для всіх основних порівнянь з baseline
- [ ] **95% Bootstrap CI** наведено для всіх метрик
- [ ] **Cohen's d** обчислено (практична значущість при d > 0.5)
- [ ] Використано парний Wilcoxon або t-test (залежно від нормальності)

### Перевірка припущень
- [ ] Проведено Shapiro-Wilk test для перевірки нормальності
- [ ] Проведено Levene's test для перевірки гомогенності дисперсій
- [ ] Обґрунтовано вибір статистичного тесту

## 🔬 Експериментальні вимоги

### Дані
- [ ] Використано **відкриті офіційні джерела**: ASSISTments, MiniGrid, OpenML-CC18
- [ ] SHA-256 хеш даних задокументовано
- [ ] Синтетичні дані використано лише для контрольованого дрейфу (не як основа)

### Режими середовища
- [ ] Стабільний режим (без дрейфу)
- [ ] Шумовий режим (висока дисперсія)
- [ ] Контрольований дрейф (зміни розподілу)

## 🎯 Перевірка гіпотез

### H1: Детектор дрейфу
- [ ] Адаптаційна затримка зменшена ≥ 30%
- [ ] Помилкові перемикання ≤ 15%
- [ ] Статистично значуще (p < 0.05)

### H2: Багатокритеріальна утиліта
- [ ] Дисперсія знижена ≥ 20%
- [ ] Hypervolume покращено
- [ ] Статистично значуще (p < 0.05)

### H3: Мета-прунінг
- [ ] Час прийняття рішення скорочено ≥ 40%
- [ ] Net utility не постраждала статистично значуще
- [ ] Статистично значуще (p < 0.05)
